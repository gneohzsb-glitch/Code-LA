# واژه‌نامه

| اصطلاح | تعریف |
|---|---|
| **eBPF** | Extended Berkeley Packet Filter؛ فناوری اجرای برنامه‌های ایمن در کرنل که verifier آن را پیش از اجرا اثبات می‌کند |
| **حسگر (Sensor)** | برنامهٔ eBPF ARGUS؛ ۲۱ kprobe که رویداد خام را در ring buffer می‌گذارد |
| **سپر (Shield)** | ماژول کرنل ARGUS؛ ۴ kprobe که از دیمن محافظت می‌کند |
| **دیمن (Daemon)** | سرویس ARGUS که رویداد خام را به بلوک زنجیرشده تبدیل می‌کند (در `argus-cli service status` با نقش *capture engine* نشان داده می‌شود) |
| **بلوک (Block)** | یک خط JSON که یک رویداد را با هش به بلوک قبلی زنجیر می‌کند |
| **زنجیرهٔ هش** | توالی بلوک‌ها که هرکدام هش بلوک قبلی را در خود دارد |
| **جنسیس (Genesis)** | بلوک اول؛ `prev_hash` آن ۶۴ صفر است |
| **kprobe** | نقطهٔ قلاب کرنل که اجرای یک تابع را می‌گیرد |
| **ring buffer** | بافر حلقه‌ای کرنل که حسگر رویدادها را در آن می‌گذارد |
| **CO-RE** | Compile Once – Run Everywhere؛ خواندن ساختارهای کرنل بدون وابستگی به نسخه |
| **verifier** | بخشی از کرنل که ایمنی برنامهٔ eBPF را پیش از اجرا اثبات می‌کند |
| **immutable** | پرچم فایل‌سیستم (`FS_IMMUTABLE_FL`) که بازنویسی/حذف را مسدود می‌کند |
| **آرشیو** | فایل `.log.gz` یک روز گذشته، فشرده و مهرشده |
| **تجمیع (Aggregation)** | جمع‌کردن خواندن‌های تکراری در یک بلوک خلاصهٔ شمارش‌دار، بدون حذف |
| **allowlist** | فهرست قواعدی که مشخص می‌کند کدام (فایل اجرایی، پیشوند مسیر) می‌تواند تجمیع شود |
| **پرچم حساس (SENSITIVE)** | نشانهٔ دسترسی به مسیر حساس؛ در فیلد `f` ذخیره می‌شود (هش‌نشده) |
| **فیلتر نویز** | دور ریختن خواندن‌های روتین (`/proc`, کتابخانه‌ها) |
| **ring buffer بازخورد** | حلقه‌ای که اگر دیمن رویداد خودش را ثبت کند رخ می‌دهد؛ با `daemon_pid_map` بسته شده |
| **PBKDF2** | تابع مشتق‌گیری کلید از رمز؛ ARGUS از PBKDF2-HMAC-SHA256 با ۵۰۰٬۰۰۰ تکرار استفاده می‌کند |
| **AES-256-CBC** | الگوریتم رمزنگاری متقارن برای محرمانگی محتوا |
| **قفل ماشین** | گره‌زدن کلید رمزنگاری به `machine.id`، تا لاگ کپی‌شده جای دیگر خواندنی نباشد |
| **لنگر بیرونی** | فرستادن سر زنجیره به مقصد بیرونی برای اثبات زمان |
| **مانیفست** | فایل حاوی هش SHA-256 یک بازهٔ زمانی (گواهی یکپارچگی) |
| **chain of custody** | زنجیرهٔ حضانت؛ مسیر اثبات‌شدهٔ نگه‌داری مدرک |
| **مبهم‌سازی (obfuscation)** | پنهان‌کردن مسیر/نام لاگ؛ هزینه‌ساز است، نه تضمین‌گر |
| **self-capture** | رویدادی که خود دیمن تولید می‌کند؛ باید صفر باشد |
| **حالت فیلتر** | `performance` / `balanced` / `forensic`؛ اندازهٔ پنجرهٔ تجمیع |
| **MAINTENANCE block** | بلوکی که اقدام نگهداشت را پیش از وقوع ثبت می‌کند |
