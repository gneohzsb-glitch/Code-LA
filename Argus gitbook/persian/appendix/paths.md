# مرجع مسیرها

> **دربارهٔ دامنهٔ این صفحه.** انبار رویداد — یعنی جایی که لاگ زنجیره و آرشیوهایش
> واقعاً قرار دارند — عمداً در این صفحه فهرست نشده است. بیرون نگه داشتن مکان آن از
> مستندات، بخشی از روشی است که ARGUS با آن از شاهد محافظت می‌کند. برای خواندن آن
> از فرمان‌های `argus-cli` استفاده کنید؛ آن‌ها همیشه مکان جاری را برایتان پیدا
> می‌کنند و قواعد دسترسی گروه `argus` را رعایت می‌کنند.

## باینری‌ها و منابع

| مورد | مسیر |
|---|---|
| CLI اپراتور | `/usr/local/bin/argus-cli` |
| سورس GPL (سپر + حسگر) | `/usr/local/share/argus/src/` |
| تکمیل bash | `/etc/bash_completion.d/argus-cli` |

> مسیر دیمن، کمکی و حسگر **داخلی** است و منتشر نمی‌شود. ARGUS آن‌ها را عمداً با
> نام‌هایی کاملاً عادی اجرا می‌کند؛ سند یا اسکرین‌شاتی که نامشان را بگوید آن پوشش را
> از بین می‌برد. برای دیدن وضعیتشان از `argus-cli service status` و
> `argus-cli logs` استفاده کنید.

| سیاست نگهداشت | `/etc/argus/retention.conf` |

## امنیت

| مورد | مسیر | مجوز |
|---|---|---|
| رمز حذف (هش) | `/etc/argus/remove.key` | `0600` |
| KDF رمز (PBKDF2) | `/etc/argus/pass.kdf` | `0600` |
| اثر انگشت ماشین | `/etc/argus/machine.id` | `0640 root:argus` + immutable |
| salt رمزنگاری | `/etc/argus/embedded_salt` | `0640 root:argus` + immutable |
| کلید امضای anchor | `/etc/argus/anchor.key` | `0640 root:argus` |
| توکن آزادسازی سپر | `/etc/argus/remove.key` | `0600` + immutable |

> مسیر خودِ ماژول کرنل و پارامترهای کنترلی‌اش داخلی است و منتشر نمی‌شود.
> `argus-cli status` وضعیت سپر را بدون افشای آن‌ها گزارش می‌کند.

## داده و لاگ

انبار رویداد محافظت‌شده است: با مجوز `0750` و مالکیت `root:argus`، و فقط برای root
و اعضای گروه `argus` خواندنی است. ریشهٔ دقیق آن یک جزئیات داخلی است و در اینجا
منتشر نمی‌شود.

| مورد | کجا |
|---|---|
| لاگ زنجیره (امروز) | فایل فعالِ امروز، درون انبار محافظت‌شده |
| آرشیو (روزهای گذشته) | فایل‌های فشردهٔ روزها، درون انبار محافظت‌شده |
| شمارندهٔ زنجیره | فایل شمارنده، درون انبار محافظت‌شده |
| گواهی یکپارچگی | `/var/log/argus_evidence/cert_*.txt` |
| سوکت زمان اجرا | `/run/argus/ip.sock` |
| لاگ هشدار | `/var/log/argus_alerts.log` |
| لاگ صدور | `/var/log/argus_export.log` |
| لاگ لنگر | `/var/log/argus_anchor.log` |

## سرویس‌ها

دو سرویس ARGUS به‌صورت واحدهای systemd کاملاً عادی اجرا می‌شوند؛ نام واحدهایشان
داخلی است و منتشر نمی‌شود. آن‌ها را از طریق CLI اداره کنید:

| کار | فرمان |
|---|---|
| وضعیت | `argus-cli service status` |
| ری‌استارت | `sudo argus-cli service restart` |
| لاگ | `argus-cli logs --last 100` |

---

## نکته‌ها

- **تاریخ** در نام پوشه‌های انبار با **وقت ایران (UTC+3:30)** حساب می‌شود، نه UTC.
- **مهر immutable** روی آرشیوهای فشردهٔ روزها، کلید حذف، و salt رمزنگاری اعمال
  می‌شود؛ بدون ریبوت باز می‌شود.
- برای یافتن مکان جاری انبار روی میزبانی که root هستید، به‌جای حدس زدنِ مسیر از
  خودِ محصول بپرسید: CLI همان رابط پشتیبانی‌شده است.
