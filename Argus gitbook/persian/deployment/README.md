# استقرار

این بخش همه‌چیزِ بردن ARGUS روی یک هاست واقعی را پوشش می‌دهد: از الزامات، تا نصب،
پیکربندی، نگهداشت، و حذف — همه **بدون هیچ ریبوتی**.

---

## چرخهٔ عمر

```
ساخت (make) → نصب (install.sh) → پیکربندی → بهره‌برداری → به‌روزرسانی → حذف
                                       ↓
                              (همه بدون ریبوت)
```

---

## خلاصهٔ سریع

```bash
# ۱. ساخت
make

# ۲. نصب
sudo ./install.sh

# ۳. اگر رمز حذف تنظیم نشده:
sudo argus-cli set-password      # رمز را ۱۰ بار وارد کنید
sudo modprobe argus_shield
sudo argus-cli service restart

# ۴. بررسی
argus-cli status
argus-cli verify
```
