# پیکربندی

همهٔ فایل‌های پیکربندی در `/etc/argus/` قرار دارند. هیچ‌کدام به ریبوت نیاز ندارند؛ دیمن
پیکربندی را در زمان اجرا می‌خواند.

---

## خلاصهٔ فایل‌ها

| فایل | نقش | در ارتقا |
|---|---|---|
| `export.conf` | صدور/رمزنگاری | به‌روز می‌شود |
| `anchor.conf` | لنگر بیرونی | به‌روز می‌شود |
| `alert.conf` | تنظیمات هشدار | به‌روز می‌شود |
| `mode` | حالت فیلتر تجمیع | حفظ می‌شود |
| `allowlist.conf` | لیست سفید تجمیع | حفظ می‌شود |
| `retention.conf` | سیاست نگهداشت | حفظ می‌شود |

---

## `export.conf` — صدور و رمزنگاری

```ini
INTERVAL=60                    # فاصلهٔ گذرهای صدور (۱۰..۳۶۰۰ ثانیه)
DESTINATION=FILE:/var/log/argus_export.log
ENCRYPT=0                      # ۱ = رمزنگاری خطوط جدید
ENCRYPT_KEY_SOURCE=machine     # تنها منبع پشتیبانی‌شده
```

**`DESTINATION`:** `FILE:<path>` یا `TCP:<host:port>` یا `UDP:<host:port>`.

**`ENCRYPT`:** با `1`، خطوط جدید رمز می‌شوند. روزهای قبلی متن ساده می‌مانند و کنار
روزهای جدید کار می‌کنند. خواندن لاگ رمزشده نیاز به `sudo` دارد (salt فقط root خواندنی
است). جزئیات در [رمزنگاری](../security/encryption.md).

---

## `anchor.conf` — لنگر بیرونی

```ini
INTERVAL=300                   # فاصلهٔ ارسال لنگر (۱۰..۸۶۴۰۰ ثانیه)
DESTINATION=FILE:/var/log/argus_anchor.log
FORMAT=JSON
```

سر زنجیره (head hash) به‌طور دوره‌ای به مقصد بیرونی فرستاده می‌شود تا **اثبات زمان**
(timestamp anchoring) ممکن شود: اگر بعداً کسی کل زنجیره را بازنویسی کند، هش لنگرشده
دیگر با سر زنجیره نمی‌خواند.

---

## `alert.conf` — هشدار

```ini
MIN_RISK_SCORE=30              # حداقل امتیاز ریسک برای هشدار
```

قواعد تشخیص، کامپایل‌شده هستند؛ این فایل آستانه را تنظیم می‌کند.

---

## `mode` — حالت فیلتر تجمیع

یک عدد (`0`, `1`, `2`) یا از CLI:

```bash
argus-cli mode                   # نمایش
sudo argus-cli mode balanced     # performance | balanced | forensic
```

| مقدار | نام | پنجره |
|---|---|---|
| 0 | performance | ۳۶۰۰s |
| 1 | balanced (پیش‌فرض) | ۳۰۰s |
| 2 | forensic | ۰ (بدون تجمیع) |

هیچ حالتی ثبت را خاموش نمی‌کند.

## `allowlist.conf` — لیست سفید تجمیع

هر خط می‌گوید: «این فایل اجرایی مشخص می‌تواند زیر این پیشوند مسیر بخواند، بدون بلوک
فردی؛ در یک شمارندهٔ پنجره جمع کن.»

```
<exe_path>|<path_prefix>|<max_count_per_window>
```

| بخش | معنی |
|---|---|
| `exe_path` | مسیر مطلق باینری، تطبیق دقیق (از `/proc/<pid>/exe`، **نه** `comm`) |
| `path_prefix` | با ابتدای مسیر بازشده تطبیق می‌شود |
| `max_count` | عددی بالای این حد هنوز تجمیع می‌شود، ولی خلاصه به‌عنوان ناهنجاری پرچم می‌خورد؛ `0` = بدون سقف |

**فایل عرضه‌شده عمداً خالی است.** allowlist باید از دادهٔ واقعی استخراج شود، نه حدس. تا
زمانی که خالی است، هیچ رویدادی تجمیع نمی‌شود.

> **مهم:** فقط **خواندن** تجمیع می‌شود. نوشتن زیر یک پیشوند مجاز، همیشه بلوک فردی است.

نمونهٔ استخراج:

```bash
argus-cli export --format csv --from 09/01/2026 \
  | awk -F, '{print $<comm>","$<path>}' | sort | uniq -c | sort -rn | head
```

## `retention.conf` — سیاست نگهداشت

```ini
RETENTION_MODE=off             # off | archive | auto
RETENTION_THRESHOLD_PERCENT=85
RETENTION_DELETE_PERCENT=20
RETENTION_ARCHIVE_PATH=
```

جزئیات کامل در [نگهداشت](retention.md). این فایل هر گذر توسط دیمن بازخوانی می‌شود، پس
تغییر آن **بدون ری‌استارت** اعمال می‌شود.

---

## اعمال تغییرات

| فایل | نحوهٔ اعمال |
|---|---|
| `retention.conf` | خودکار، گذر بعدی (≤۱۰ دقیقه) |
| `mode` | خودکار، ≤۵ ثانیه |
| `allowlist.conf` | خودکار |
| `export.conf` / `anchor.conf` | نیاز به `argus-cli service restart` |

هیچ‌کدام به ریبوت نیاز ندارند.
