# قابلیت استناد فارنزیک

یک سابقه وقتی می‌تواند به‌عنوان **مدرک** ارائه شود که بتوان زنجیرهٔ حضانت
(chain of custody) و دست‌نخوردگی آن را نشان داد. ARGUS سه ابزار فنی برای این کار دارد.

---

## ابزار ۱ — زنجیرهٔ هش

هر بلوک به بلوک قبلی زنجیر شده است. هر تغییری (ویرایش، حذف، جابه‌جایی) قابل کشف است.

```bash
sudo argus-cli verify
# ALL 368137 BLOCKS VERIFIED — NO BREAKS
```

اگر زنجیره شکسته باشد، عدد شکاف‌ها گزارش می‌شود:

```bash
# 18 BROKEN LINKS / 0 BAD HASHES / 126369 BLOCKS
```

این یعنی می‌توان گفت: «این سابقه در بازهٔ X هیچ شکافی ندارد» یا «در بلوک N شکسته
است» — هر دو گزارهٔ قابل استناد.

---

## ابزار ۲ — گواهی یکپارچگی (مانیفست)

```bash
sudo argus-cli integrity --from 09/01/2026 --to 09/30/2026
```

خروجی یک هش SHA-256 برای کل بازه است. مزیت کلیدی: **حسابرس می‌تواند مستقل تأیید کند**،
حتی بدون نصب ARGUS:

```bash
sha256sum <ARGUS_STORE>/2026/September/30.log.gz
# باید با هش مانیفست بخواند
```

این «تأیید مستقل» برای استناد حقوقی مهم است: صحت سابقه به اعتماد به سازندهٔ نرم‌افزار
گره نمی‌خورد.

---

## ابزار ۳ — لنگر بیرونی (اثبات زمان)

سر زنجیره به‌طور دوره‌ای به یک مقصد بیرونی فرستاده می‌شود. اگر بعداً کسی کل زنجیره را
بازنویسی کند، هش لنگرشده دیگر با سر زنجیره نمی‌خواند.

| کاربرد | توضیح |
|---|---|
| اثبات اینکه سابقه از تاریخ X وجود داشته | لنگرِ timestamp‌دار |
| کشف بازنویسی کل زنجیره | ناسازگاری با لنگر |

---

## زنجیرهٔ حضانت

ARGUS مسیر زیر را برای یک سند قابل استناد فراهم می‌کند:

```
۱. رویداد در کرنل ثبت می‌شود (بدون امکان دور زدن از فضای کاربر)
۲. به بلوک زنجیرشده تبدیل می‌شود (هش روی محتوا)
۳. روی دیسک نوشته می‌شود
۴. روز گذشته فشرده و مهر immutable می‌شود
۵. verify / integrity صحت را اثبات می‌کند
۶. مانیفست مستقل با sha256sum تأیید می‌شود
```

هر گام قابل بازرسی است.

---

## محدودیت‌هایی که باید بدانید

| محدودیت | اثر |
|---|---|
| در برابر root مصمم، سپر تسلیم می‌شود | اگر مهاجم از قبل root داشته، می‌تواند `reboot`/`kexec` کند |
| ساعت سیستم | timestamp دیوار به ساعت هاست وابسته است؛ لنگر بیرونی کمک می‌کند |
| پیش از نصب ARGUS | رویدادهای قبلی ثبت نشده‌اند |
| ~۱٫۹٪ رویداد `openat` بدون مسیر | ثبت می‌شوند ولی مسیرشان ناشناخته است |

صداقت دربارهٔ این محدودیت‌ها، خودش بخشی از ارزش فارنزیک است.

---

## توصیه برای ارائهٔ مدرک

1. `integrity` را برای بازهٔ مورد نظر اجرا و مانیفست را ذخیره کنید.
2. `verify` را اجرا و خروجی `NO BREAKS` را ثبت کنید.
3. هش لنگرهای بیرونی مرتبط را ضمیمه کنید.
4. مسیر فایل‌ها را با `sha256sum` مستقل تأیید کنید.
5. تاریخ‌ها را با وقت ایران (UTC+3:30) تفسیر کنید.

جزئیات فنی فرمول و انواع بلوک در [زنجیرهٔ هش](../architecture/blockchain.md).
