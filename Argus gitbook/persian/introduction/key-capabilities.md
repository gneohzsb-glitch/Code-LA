# قابلیت‌های کلیدی

## ثبت و یکپارچگی

| قابلیت | توضیح |
|---|---|
| **ثبت در سطح کرنل** | حسگر eBPF، ۲۱ syscall کلیدی (فایل، مجوز، ماژول، سیگنال) |
| **زنجیرهٔ هش** | `h = SHA-256(prev_hash + event + timestamp + uid + pid)` — هر بلوک به بلوک قبلی قفل است |
| **کشف دست‌کاری** | `verify` هم *لینک* و هم *هش* هر بلوک را بازمحاسبه می‌کند؛ ویرایش محتوا، جابه‌جایی و حذف میانی هر سه کشف می‌شوند |
| **گواهی یکپارچگی** | مانیفست SHA-256 برای یک بازهٔ زمانی؛ مدرک قابل ارائه و قابل تأیید مستقل |
| **لنگر بیرونی** | فرستادن سر زنجیره به یک مقصد بیرونی برای اثبات زمان (timestamp anchoring) |

## حفاظت از خود

| قابلیت | توضیح |
|---|---|
| **سپر کرنل** | ماژول کوچک با ۴ kprobe؛ جلوی `kill`/`killall`/`killpg` روی دیمن و `rmmod`/`rmmod -f` را می‌گیرد |
| **مسیر آزادسازی** | توکن رمزدار؛ بدون آن سپر **اصلاً بار نمی‌شود** (پس هیچ‌وقت قفل ریبوتی رخ نمی‌دهد) |
| **مهر آرشیو** | روزهای گذشته با پرچم `immutable` مهر می‌شوند؛ بازکردن با `chattr -i` و بدون ریبوت |
| **تاب‌آوری دیمن** | واحد systemd با `Restart=always`؛ اگر دیمن کرش کند، خودکار برمی‌گردد و سپر را دوباره مسلح می‌کند |

## کارایی و نگهداشت

| قابلیت | توضیح |
|---|---|
| **فیلتر نویز** | خواندن‌های روتین (`/proc`، کتابخانه‌ها) ثبت نمی‌شوند؛ نوشتن روی همان مسیرها ثبت می‌شود |
| **تجمیع رویداد** | خواندن‌های تکراریِ شناخته‌خسته‌کننده در یک بلوک خلاصهٔ شمارش‌دار جمع می‌شوند — **حذف نمی‌شوند** |
| **نگهداشت بی‌اتلاف** | روزهای گذشته فشرده می‌شوند (~۵× کوچک‌تر)، **هرگز حذف نمی‌شوند**، و مهر می‌خورند |
| **حالت‌های نگهداشت** | `off` (پیش‌فرض)، `archive` (انتقال به رسانهٔ بیرونی)، `auto` (حذف) — هر دو حالت اخیر اختیاری |
| **هشدار ۸۵٪** | اپراتور پیش از پر شدن دیسک هشدار می‌گیرد و خودش تصمیم می‌گیرد |

## امنیت و یکپارچه‌سازی

| قابلیت | توضیح |
|---|---|
| **رمزنگاری اختیاری** | AES-256-CBC با کلید قفل‌شده به ماشین (PBKDF2-HMAC-SHA256، ۵۰۰٬۰۰۰ تکرار) |
| **پرچم مسیر حساس** | دسترسی به `/etc/shadow`، کلیدهای SSH، `/root/` و… با پرچم جدا ثبت و به SIEM علامت‌دار می‌شود |
| **صدور به SIEM** | خروجی JSON/CSV + فوروارد زندهٔ syslog با تگ `ARGUS_SENSITIVE` |
| **پنهان‌سازی مسیر** | لاگ‌ها زیر یک مسیر و نام مبدل نگه داشته می‌شوند تا نگاهی سرسری به فایل‌سیستم آن‌ها را آشکار نکند |

## چه چیزی ARGUS **نیست**

صداقت دربارهٔ مرزها، بخشی از طراحی است:

- **ضدویروس نیست.** ARGUS رویداد را ثبت می‌کند، جلوی نفوذ را نمی‌گیرد.
- **در برابر root مصمم ادعای ناممکن ندارد.** root می‌تواند `reboot`، `kexec` یا
  `cgroup.kill` کند. هدف، مسدود کردن مسیرهای بدیهی و بالا بردن هزینه است.
- **رمزنگاری به‌طور پیش‌فرض خاموش است.** روشن کردنش تصمیم اپراتور است.
- **جایگزین SIEM نیست.** ARGUS *منبع* رویداد قابل‌اعتماد تولید می‌کند؛ SIEM آن را
  جمع‌آوری و هم‌بستگی می‌کند.
