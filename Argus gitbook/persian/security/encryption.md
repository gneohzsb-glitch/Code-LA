# رمزنگاری

رمزنگاری لاگ ARGUS **اختیاری** است و به‌طور پیش‌فرض **خاموش** است. وقتی روشن شود، محتوای
هر خط با AES-256-CBC رمز می‌شود و کلید به ماشین قفل می‌شود — لاگِ کپی‌شده روی ماشین
دیگری خواندنی نیست.

---

## روشن و خاموش کردن

```bash
# روشن
sudo sed -i 's/^ENCRYPT=.*/ENCRYPT=1/' /etc/argus/export.conf
sudo argus-cli service restart

# خاموش
sudo sed -i 's/^ENCRYPT=.*/ENCRYPT=0/' /etc/argus/export.conf
sudo argus-cli service restart
```

پس از روشن شدن، خطوط تازه با نشان `AGRS1:` شروع می‌شوند:

```bash
sudo tail -1 <ARGUS_STORE>/2026/October/01.log | cut -c1-40
# AGRS1:...
```

---

## مشتق‌گیری کلید

```
key = PBKDF2-HMAC-SHA256( machine.id + embedded_salt, 500000 iterations )
```

- `machine.id` = اثر انگشت ماشین (hostname + machine-id + MAC + CPU)
- `embedded_salt` = ۳۲ بایت تصادفی، فقط برای root خواندنی، مهر `immutable`
- **کلید هیچ‌جا روی دیسک ذخیره نمی‌شود** — هر بار مشتق می‌شود

نتیجه: کپی لاگ + کپی `embedded_salt` روی ماشین دیگر **کافی نیست**، چون `machine.id`
عوض شده است.

---

## قالب خط

```
AGRS1:<base64( IV || ciphertext )>
```

- `AGRS1` = نشان نسخه
- خطی که این نشان را ندارد، متن سادهٔ نسخه‌های قبلی است

پس روزهای قدیمی (متن ساده) و جدید (رمز) در یک پوشه کنار هم کار می‌کنند و **نیازی به
مهاجرت نیست**.

---

## هش روی متن ساده حساب می‌شود

ترتیب مهم است:

1. هش زنجیره روی **متن ساده** و **پیش از** رمزنگاری حساب می‌شود.
2. `verify` اول رمزگشایی می‌کند، بعد هش را چک می‌کند.

بنابراین رمزنگاری برای زنجیره **شفاف** است و هیچ‌چیز در فرمول هش تغییر نمی‌کند.

---

## سه نقطهٔ اتصال

| نقطه | کار |
|---|---|
| `storage_write_line` | خط را پیش از نوشتن رمز می‌کند |
| `storage_last_block` | برای ادامهٔ زنجیره، آخرین خط را رمزگشایی می‌کند |
| `export_handler` و همهٔ خواننده‌های `cli.c` | اول رمزگشایی، بعد پردازش |

`retention` و `evidence` بی‌تغییر کار می‌کنند (دومی بایت‌های فایل را هش می‌کند، پس
رمزنگاری برایش شفاف است).

---

## نکتهٔ بهره‌برداری

`embedded_salt` فقط برای root خواندنی است. پس خواندن لاگ رمزنگاری‌شده نیاز به `sudo`
دارد. اگر بدون root اجرا کنید، `verify` صریحاً تعداد بلوک‌های خوانده‌نشده را گزارش
می‌کند:

```
◆ 237 ENCRYPTED BLOCK(S) SKIPPED
```

این گزارش‌دهی صادقانه عمدی است: بهتر از سکوت کردن دربارهٔ بلوک‌های تأییدنشده.

---

## ملاحظات امنیتی

| موضوع | وضعیت |
|---|---|
| الگوریتم | AES-256-CBC |
| مشتق‌گیری کلید | PBKDF2-HMAC-SHA256، ۵۰۰٬۰۰۰ تکرار (مقاوم در برابر brute-force) |
| IV | تصادفی برای هر خط |
| قفل ماشین | بله — کلید به `machine.id` گره خورده |
| ذخیرهٔ کلید روی دیسک | خیر |
| رمزنگاری تأییدشده (AEAD) | خیر — CBC + زنجیرهٔ هش، یکپارچگی را از هش می‌گیرد |

> **توجه:** CBC به‌تنهایی محرمانگی می‌دهد، نه احراز اصالت. در ARGUS، یکپارچگی از
> **زنجیرهٔ هش** می‌آید، نه از رمزنگاری. این تفکیک عمدی است.
