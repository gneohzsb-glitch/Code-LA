# مقاومت در برابر دست‌کاری

ARGUS در دو جبهه از خود دفاع می‌کند: **یکپارچگی داده** (نمی‌توان لاگ را بی‌سروصدا عوض
کرد) و **بقای سامانه** (نمی‌توان دیمن را کشت یا ماژول را برداشت).

---

## جبههٔ اول: یکپارچگی داده

زنجیرهٔ هش تضمین می‌کند هر تغییر در سابقه، قابل کشف است. `argus-cli verify` هم لینک و
هم هش را بازمحاسبه می‌کند:

| حمله | نتیجه |
|---|---|
| ویرایش محتوای یک بلوک | `BAD HASHES` |
| جابه‌جایی/دوباره‌لینک‌کردن | `BROKEN LINKS` |
| حذف بلوک از میانه | `BROKEN LINKS` |
| حذف کل فایل | شکاف تاریخ در ترتیب روزها |

جزئیات فرمول و انواع بلوک در [زنجیرهٔ هش](../architecture/blockchain.md).

---

## جبههٔ دوم: بقای سامانه

سپر کرنل (۴ kprobe) جلوی مسیرهای بدیهی را می‌گیرد:

| تلاش مهاجم | نتیجه |
|---|---|
| `kill -9 <daemon>` | syscall «موفق» گزارش می‌شود، ولی سیگنالی نمی‌رسد |
| `kill -9 -1` (broadcast) | خنثی می‌شود |
| `killpg` (process group) | خنثی می‌شود |
| `rmmod argus_shield` | `Module is in use` |
| `rmmod -f argus_shield` | `Resource temporarily unavailable` |

**نکتهٔ کلیدی:** syscall **خطا نمی‌دهد**. مهاجم هیچ نشانه‌ای از وجود سپر نمی‌بیند — نه
`EPERM`، نه پیام خطا. این «بی‌اثر‌کردن بی‌صدا» است، نه «رد‌کردن پرسروصدا».

---

## استثنای PID 1

سپر عمداً سیگنال از PID 1 (systemd) را رد نمی‌کند. بدون این، `systemctl stop/restart`
قفل می‌شد و هر به‌روزرسانی به رمز حذف نیاز داشت.

```bash
sudo argus-cli service restart   # کار می‌کند، بدون رمز
sudo kill -9 $DPID                              # هنوز مسدود است
```

---

## تاب‌آوری دیمن

واحد systemd با `Restart=always` و `RestartSec=3` تنظیم شده است. اگر دیمن به هر دلیلی
کرش کند، systemd خودش آن را برمی‌گرداند و سپر را دوباره مسلح می‌کند. نیازی به thread
کرنل برای احیا نیست — این کار را مدیر سرویس استاندارد انجام می‌دهد.

---

## مسیر آزادسازی: چرا قفل نمی‌شویم

بدون یک مسیر خروج، هر قفل‌شدنی به «فقط با ریبوت باز می‌شود» تبدیل می‌شد. ARGUS این را
ممنوع کرده:

- سپر **بدون توکن آزادسازی بار نمی‌شود** (`-ENOENT`).
- توکن = هش SHA-256 رمز حذف در `/etc/argus/remove.key`.
- توکن **در هر تلاش بازخوانی می‌شود**، پس تغییر رمز، حذف را غیرممکن نمی‌کند.
- توکن قدیمی (زمان بارگذاری) هم پذیرفته می‌شود، پس پاک‌کردن فایل اپراتور را قفل نمی‌کند.

```bash
sudo argus-cli release    # رمز حذف را می‌پرسد و سپر را آزاد می‌کند
```

## آزمون‌های اثبات

این ادعاها با تست خودکار تأیید می‌شوند:

| مجموعهٔ تست | چه چیزی را اثبات می‌کند |
|---|---|
| `test_shield.sh` | کشتن دیمن، `rmmod`، `rmmod -f`، مسیر آزادسازی |
| `test_shield_reduction.sh` | سپر دقیقاً ۴ هوک دارد |
| `test_verify.sh` | ویرایش، دوباره‌لینک، و حذف کشف می‌شوند |
| `test_retention.sh` | فشرده‌سازی بی‌اتلاف + مهر immutable |

جزئیات در [تست‌ها](../appendix/testing.md).
