# ARGUS

**سامانهٔ ثبت رویداد در سطح کرنل برای فارنزیک و حسابرسی امنیتی**

> نسخهٔ ۱۵٫۴ · سازنده: Gneo HZSB

ARGUS هر رویداد مهم سیستم را در لحظهٔ وقوع می‌گیرد، آن را به یک بلوک با هش
SHA-256 تبدیل می‌کند که به بلوک قبلی زنجیر شده است، و روی دیسک می‌نویسد. نتیجه یک
**زنجیرهٔ دست‌کاری‌ناپذیر** است: اگر کسی حتی یک بایت از لاگ را عوض یا حذف کند،
`argus-cli verify` آن را نشان می‌دهد.

هدف عملی ساده است: پس از یک نفوذ — یا برای اثبات انطباق — بتوان با اطمینان پاسخ داد:

> **چه رویدادی، توسط چه کاربر/فرآیندی، کِی رخ داد، و آیا کسی لاگ را دست‌کاری کرده است؟**

## نگاه یک‌نگاهی

| ویژگی | ARGUS |
|---|---|
| ثبت رویداد | در سطح کرنل، با حسگر eBPF (۲۱ هوک syscall) |
| دست‌کاری‌ناپذیری | زنجیرهٔ هش SHA-256؛ هر بلوک به بلوک قبلی قفل است |
| حفاظت از خود | ماژول «سپر» جلوی کشتن دیمن و برداشتن ماژول را می‌گیرد |
| نگهداشت | روزهای گذشته فشرده و مهر می‌شوند؛ **به‌صورت پیش‌فرض هرگز حذف نمی‌شوند** |
| رمزنگاری | اختیاری، AES-256-CBC با کلید قفل‌شده به ماشین |
| نیاز به ریبوت | **ندارد** — نه برای نصب، نه برای به‌روزرسانی، نه برای حذف |
| یکپارچه‌سازی | خروجی JSON/CSV، فوروارد زندهٔ syslog، گواهی یکپارچگی |

## شروع سریع

```bash
make                 # ساخت همه‌چیز از صفر
sudo ./install.sh    # نصب
argus-cli status     # وضعیت سپر، دیمن، رمز، مصرف دیسک
argus-cli verify     # تأیید زنجیره
```

راهنمای کامل در [نصب](deployment/installation.md) و [مرجع CLI](cli-reference/README.md).
