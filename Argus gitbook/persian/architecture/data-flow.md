# جریان داده

مسیر یک syscall از لحظهٔ وقوع در کرنل تا تبدیل به یک خط زنجیرشده روی دیسک:

```
syscall
   │
   ├─ kprobe حسگر ──→ ring buffer ──→ reader.c
   │                                    │
   │                                    ├─ فیلتر: خود دیمن؟ رد شو
   │                                    └─ فیلتر: مسیر خود لاگ؟ رد شو
   │                                          │
   │                          classifier.c: DROP / KEEP / AGGREGATABLE
   │                                          │
   │       خواندنِ پوشش‌دادهٔ allowlist ──→ aggregator.c (شمارنده + sidecar)
   │                                          │
   │                          بقیه ───────────→ blockchain_add_event()
   │                                      • متن رویداد
   │                                      • escape JSON همهٔ فیلدها
   │                                      • ipcache_lookup(pid)
   │                                      • h = sha256(ph + e + t + u + p)
   │                                      • storage_write_line()
   │                                          │
   └─ kprobe سپر ──→ اگر هدف دیمن بود، آرگومان صفر شود
```

---

## گام‌به‌گام

| گام | مؤلفه | کار |
|---|---|---|
| ۱ | kprobe حسگر | syscall را می‌گیرد، رویداد خام را در ring buffer می‌گذارد |
| ۲ | `reader.c` | از ring buffer می‌خواند؛ رویداد خود دیمن و مسیر خود لاگ را دور می‌ریزد |
| ۳ | `classifier.c` | تصمیم `DROP` / `KEEP` / `AGGREGATABLE` |
| ۴ | `aggregator.c` | اگر خواندنِ پوشش‌دادهٔ allowlist باشد، شمارنده را زیاد می‌کند |
| ۵ | `blockchain.c` | متن رویداد، escape JSON، `ipcache_lookup`، محاسبهٔ هش |
| ۶ | `storage.c` | نوشتن خط در مسیر استتارشده |
| ۷ | سپر (موازی) | اگر هدف سیگنال دیمن بود، آرگومان را صفر می‌کند |

---

## نقاط اتصال فیلتر

سه نقطهٔ تصمیم در مسیر وجود دارد:

1. **ضد فیدبک (`reader.c`):** رویدادهایی که خود دیمن تولید کرده، و هر دسترسی به خودِ
   فایل لاگ، پیش از هر پردازش دیگری حذف می‌شوند. این حلقهٔ بازخورد را می‌بندد.

2. **طبقه‌بند (`classifier.c`):** فقط روی `openat`. سه خروجی دارد:
   - `DROP` — نویز محض (خواندن کتابخانه، `/proc`، …)
   - `KEEP` — رویداد ارزشمند (نوشتن، مسیر حساس، …)
   - `AGGREGATABLE` — خواندنِ خسته‌کننده که باید شمرده شود، نه حذف

3. **تجمیع (`aggregator.c`):** فقط `AGGREGATABLE`های پوشش‌دادهٔ allowlist را می‌شمارد.
   بقیه بی‌درنگ به `blockchain_add_event()` می‌روند.

---

## نوشتن امن روی دیسک

`storage.c` خط را با یک نوشتن append می‌نویسد. برای ادامهٔ زنجیره پس از ری‌استارت،
آخرین بلوک روز خوانده می‌شود — از `.log` یا `.log.gz`. اگر رمزنگاری روشن باشد، خطوط
`AGRS1:` اول رمزگشایی می‌شوند.

مسیر نوشتن:
```
<ARGUS_STORE>/<سال>/<ماه>/<روز>.log
```
تاریخ با **وقت ایران (UTC+3:30)** حساب می‌شود، نه UTC.

---

## مسیر سپر (موازی)

سپر مستقل از جریان ثبت کار می‌کند. kprobeهای آن فقط وقتی دخالت می‌کنند که هدف سیگنال
یا حذف، دیمن محافظت‌شده باشد. در آن حالت آرگومان صفر می‌شود و syscall بی‌اثر می‌گذرد —
بدون خطا، بدون لاگ، بدون نشانه.
