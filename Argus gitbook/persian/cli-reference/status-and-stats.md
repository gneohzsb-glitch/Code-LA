# status و stats

## `argus-cli status`

نمای کلی وضعیت سامانه:

```bash
argus-cli status
```

```
   ╔══════════════════════════════════════════════════════════╗
   ║              ARGUS // SURVEILLANCE SYSTEM              ║
   ╚══════════════════════════════════════════════════════════╝

  SHIELD:    ◆ ACTIVE
  RELEASE:   ◆ locked
  DAEMON:    ◆ 712
  LICENSE:   ◆ VALID (2026-12-31, 88 days)
  PASSWORD:  ◆ SET
  STORAGE:   ◆ 93% used  [!] HIGH — free space or archive old days
```

| خط | معنی |
|---|---|
| `SHIELD` | آیا ماژول سپر بار است |
| `RELEASE` | `locked` (توکن مسلح) یا `released` |
| `DAEMON` | PID دیمن محافظت‌شده، یا `NOT PROTECTED` |
| `LICENSE` | وضعیت مجوز و روزهای باقی‌مانده |
| `PASSWORD` | آیا رمز حذف تنظیم شده |
| `STORAGE` | درصد مصرف دیسک؛ بالای ۸۵٪ هشدار می‌دهد |

> برای دیدن خط `PASSWORD`، دستور را با `sudo` اجرا کنید (فایل رمز فقط root خواندنی است).

## `argus-cli count`

شمارش کامل بلوک‌ها در چهار بازه:

```bash
argus-cli count
```

```
  ◆ BLOCK COUNT

  Today:   32768
  Week:    196412
  Month:   154585
  Total:   368483
```

| بازه | تعریف |
|---|---|
| `Today` | امروز (وقت ایران) |
| `Week` | ۷ روز اخیر |
| `Month` | ماه جاری |
| `Total` | تمام سابقه |

`count` هم روزهای فشرده (`.log.gz`) و هم روزهای رمزشده را می‌شمارد.

---

## `argus-cli stats`

شمارش سریع بلوک‌های امروز:

```bash
argus-cli stats
```

برای تفکیک کامل بازه‌ها از `count` استفاده کنید.

## `argus-cli service` و `argus-cli logs`

```bash
argus-cli service status
```

```
  ◆ ARGUS SERVICES

  capture engine  active
  resolver        active
```

| خط | معنا |
|---|---|
| `capture engine` | دیمنی که ثبت، زنجیره‌سازی و ذخیره می‌کند |
| `resolver` | کمکی‌ای که PID را به IP مقصد نگاشت می‌کند |

`sudo argus-cli service restart` هر دو را ری‌استارت می‌کند. ری‌استارت حسگر eBPF را جدا
می‌کند و یک شکاف ثبت به‌جا می‌گذارد؛ پس تا وقتی باینری جدیدی نصب نکرده‌اید، تغییر
پیکربندی (که در ۵ ثانیه اعمال می‌شود) را ترجیح دهید.

```bash
argus-cli logs --last 100
```

`logs` آخرین N خطِ لاگ سرویس را چاپ می‌کند (پیش‌فرض ۴۰). لاگ **از طریق ARGUS** خوانده
می‌شود، پس هیچ نام سرویسی لازم نیست تایپ یا نمایش داده شود.

> **سرویس‌ها با نقش نام‌گذاری می‌شوند.** ARGUS سرویس‌هایش را عمداً با نام‌هایی کاملاً عادیِ
> systemd اجرا می‌کند؛ CLI هرگز آن‌ها را چاپ نمی‌کند و این کتاب هم همین‌طور. برای دیدنشان از
> `service status` / `logs` استفاده کنید.

## کدهای تشخیصی

وقتی فرمانی شکست می‌خورد، آخرین خط یک کد کوتاه و مبهم حمل می‌کند:

```
  ◆ ACCESS DENIED [ARG-205]
```

کد، خطا را بدون توصیف سازوکار داخلی ARGUS مشخص می‌کند. آن را به پشتیبانی بگویید؛ معنا در
سمت ما جست‌وجو می‌شود. خروجی عادی (`◆` سبز) هیچ کدی ندارد.

## تفاوت `status` و `stats` و `count`

| دستور | چه چیزی | سرعت |
|---|---|---|
| `status` | وضعیت سامانه (سپر، دیسک، رمز) | فوری |
| `stats` | تعداد بلوک امروز | سریع |
| `count` | چهار بازهٔ شمارشی (امروز/هفته/ماه/کل) | کمی کندتر (کل درخت را می‌خواند) |
