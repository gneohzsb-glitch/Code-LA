# سپر و رمز

## `argus-cli set-password`

تنظیم رمز حذف (اولین بار):

```bash
sudo argus-cli set-password
```

رمز را **۱۰ بار** می‌پرسد و در `/etc/argus/remove.key` (به‌صورت هش SHA-256) ذخیره
می‌کند. فایل مهر `immutable` می‌خورد.

> بدون این فایل، سپر **اصلاً بار نمی‌شود** — تا هیچ‌وقت سیستمی قفل نشود که فقط با ریبوت
> باز شود.

---

## `argus-cli change-password`

تغییر رمز حذف:

```bash
sudo argus-cli change-password
```

اول رمز فعلی را می‌پرسد، سپس رمز جدید را ۱۰ بار. پس از تغییر، سپر خودش را با توکن جدید
هماهنگ می‌کند — **نیازی به ری‌استارت نیست** (توکن در هر تلاش بازخوانی می‌شود).

---

## `argus-cli release`

آزادسازی سپر و توقف دیمن **بدون** حذف باینری‌ها/تنظیمات/لاگ:

```bash
sudo argus-cli release
```

این دستور:

1. رمز حذف را می‌پرسد و توکن را به سپر می‌فرستد
2. دیمن را متوقف می‌کند
3. ماژول را برمی‌دارد

کاربرد: ارتقا، ری‌استارت تمیز، یا رفع مشکل. برای برگرداندن:

```bash
sudo argus-cli service restart
```

---

## `argus-cli remove`

حذف کامل ARGUS (**لاگ‌ها دست‌نخورده می‌مانند**):

```bash
sudo argus-cli remove
```

سپر را آزاد می‌کند → دیمن را متوقف می‌کند → ماژول را برمی‌دارد → باینری‌ها و تنظیمات را
حذف می‌کند. **پوشهٔ لاگ باقی می‌ماند.**

---

## تست دستی سپر

برای اثبات اینکه سپر کار می‌کند:

```bash
# PID دیمن محافظت‌شده
DPID=$(sudo cat /sys/module/argus_shield/parameters/argus_daemon_pid)

# ۱) تلاش برای کشتن دیمن
sudo kill -9 $DPID
echo "kill rc=$?"              # rc=0 — یعنی «موفق»!
ps -p $DPID -o pid,comm        # ولی فرآیند هنوز زنده است

# ۲) تلاش برای برداشتن ماژول
sudo rmmod argus_shield
# rmmod: ERROR: Module argus_shield is in use

# ۳) تلاش با اجبار
sudo rmmod -f argus_shield
# rmmod: ERROR: could not remove module argus_shield: Resource temporarily unavailable

# ۴) آزادسازی درست
sudo argus-cli release
```

**نکتهٔ کلیدی:** syscall **خطا نمی‌دهد**. `kill` موفق گزارش می‌شود ولی سیگنالی نمی‌رسد.
مهاجم هیچ نشانه‌ای از وجود سپر نمی‌بیند.

> ⚠️ `sudo kill -9 -1` (broadcast) هم خنثی می‌شود. اگر سپر کار **نمی‌کرد**، این دستور
> session خودتان را هم می‌کشت.

---

## ری‌استارت سرویس با سپرِ مسلح

```bash
sudo argus-cli service restart
```

این کار می‌کند و **رمز نمی‌خواهد**: سپر عمداً سیگنال از PID 1 (systemd) را رد نمی‌کند،
وگرنه مدیر سرویس نمی‌توانست دیمن را پایین بیاورد و هر به‌روزرسانی به رمز نیاز داشت.

از یک شل معمولی (`sudo kill -9 $DPID`) هنوز مسدود است.

> ری‌استارت کامل حدود ۴۰ ثانیه طول می‌کشد.

---

## خلاصهٔ دستورهای امنیتی

| دستور | رمز می‌خواهد؟ | لاگ | باینری | تنظیمات |
|---|---|---|---|---|
| `set-password` | — (تنظیم) | حفظ | حفظ | حفظ |
| `change-password` | بله (فعلی) | حفظ | حفظ | حفظ |
| `release` | بله | حفظ | **حفظ** | **حفظ** |
| `remove` | بله | **حفظ** | حذف | حذف |
