# Data Flow

The path of a syscall from the moment it occurs in the kernel to its becoming a chained line
on disk:

```
syscall
   │
   ├─ sensor kprobe ──→ ring buffer ──→ reader.c
   │                                    │
   │                                    ├─ filter: the daemon itself? drop
   │                                    └─ filter: the log's own path? drop
   │                                          │
   │                          classifier.c: DROP / KEEP / AGGREGATABLE
   │                                          │
   │       allowlist-covered read ──→ aggregator.c (counter + sidecar)
   │                                          │
   │                          everything else ─→ blockchain_add_event()
   │                                      • event text
   │                                      • JSON-escape all fields
   │                                      • ipcache_lookup(pid)
   │                                      • h = sha256(ph + e + t + u + p)
   │                                      • storage_write_line()
   │                                          │
   └─ shield kprobe ──→ if the target was the daemon, zero the argument
```

---

## Step by step

| Step | Component | What it does |
|---|---|---|
| 1 | Sensor kprobe | Catches the syscall, places a raw event in the ring buffer |
| 2 | `reader.c` | Reads from the ring buffer; discards the daemon's own events and the log's own path |
| 3 | `classifier.c` | Decides `DROP` / `KEEP` / `AGGREGATABLE` |
| 4 | `aggregator.c` | If it is an allowlist-covered read, increments a counter |
| 5 | `blockchain.c` | Event text, JSON escaping, `ipcache_lookup`, hash computation |
| 6 | `storage.c` | Writes the line to the disguised path |
| 7 | Shield (parallel) | If the target was a signal to the daemon, zeroes the argument |

---

## Filter attachment points

There are three decision points on the path:

1. **Anti-feedback (`reader.c`):** events generated by the daemon itself, and any access to
   the log file itself, are dropped before any other processing. This closes the feedback
   loop.

2. **Classifier (`classifier.c`):** applies only to `openat`. It has three outputs:
   - `DROP` — pure noise (library reads, `/proc`, …)
   - `KEEP` — a valuable event (a write, a sensitive path, …)
   - `AGGREGATABLE` — a repetitive read that should be counted, not deleted

3. **Aggregation (`aggregator.c`):** counts only `AGGREGATABLE` events covered by the
   allowlist. Everything else goes straight to `blockchain_add_event()`.

---

## Safe disk write

`storage.c` writes the line with a single append. To continue the chain after a restart, the
last block of the day is read — from `.log` or `.log.gz`. If encryption is on, `AGRS1:` lines
are decrypted first.

The write path:

```
<ARGUS_STORE>/<year>/<month>/<day>.log
```

Dates are computed in **Iran time (UTC+3:30)**, not UTC.

---

## The shield path (parallel)

The shield works independently of the recording flow. Its kprobes intervene only when the
target of a signal or a module unload is the protected daemon. In that case the argument is
zeroed and the syscall passes as a no-op — no error, no log, no hint.
